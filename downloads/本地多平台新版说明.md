# 0.3.0-local：本地多平台记账试用版

这是基于原简记账与 0.2.0-pdd 的个人改版。包名保持 `com.github.bookkeeping`，versionCode=7，数据库版本=4。针对 OPPO Find X8 等 arm64 手机打包，仍无 INTERNET 权限。

## 已加入的使用流程

- 微信、支付宝等自动识别的新交易先进入“待确认 / 平台订单”，核对交易完成、金额、分类、账户和日期后才计入收支。旧版已经入账的记录保留，不会凭猜测改金额。
- 拼多多、小红书、抖音、闲鱼支持已配置的提交按钮事件和明确成功文案。只浏览结算页不入账，提交动作也不代表成功，仍须用户确认。
- 本次截图对应金额为小红书 9.80、抖音 27.80 与 19.80、闲鱼 35.00 与 2.21 元。优惠、分期金额、会员加购、划线价和其他款式价格不能替代本单总额。按钮上有明确应付金额时优先使用实际点击按钮上的金额；金额冲突时不自动猜测。
- 抖音月付按“抖音支付”登记下单消费，不强制建立月付负债。未来整笔还款可标记“还款不计支出”，保留记录但不重复算消费。利息、手续费需单独记支出。
- 若购物平台与微信/支付宝各产生一条待确认，请先确认原购物消费，再将另一条设为“这是已记订单的付款 / 扣款”，手工核对后关联。不凭同金额自动认定同一笔。
- 新待确认点“忽略”后，订单数据行删除，列表不保留“已忽略”。后台只保留去重标识；没有订单号时仅短期抑制重复，以免永久漏掉同金额的新消费。有订单号时保留该订单号的哈希抑制重现。
- 旧版已取消/忽略的订单在 v3→v4 迁移时清理其商品、金额等详情，仅保留去重标识。已确认消费的“取消整笔”和待确认“忽略”是不同操作。

## 悬浮确认

首页进入“待确认 / 平台订单”→“截图 / 规则 / 诊断”，勾选“显示待确认悬浮卡片”，在系统允许悬浮窗。

卡片可选择分类、确认、修改、忽略或稍后核对。金额不明时禁用直接确认，需打开应用核对。系统保护的支付页面、锁屏、权限拒绝或后台限制下可能不显示，通知和待确认列表是备用入口。未提供系统权限时不能承诺始终弹窗。

确认的分类会按平台、商品/商户和收支方向保存本地偏好，后续同样文本可复用。不是云端 AI，也不会自动学会新的页面结构。

## 离线截图补记

从“截图 / 规则 / 诊断”选择截图，使用打包在 APK 内的 ML Kit 中文模型识别。无需网络或 Google Play 服务下载模型。只读取用户选中的图片，不扫图库、不保存图片、不上传。

选平台并检查 OCR 文本，进入确认页选择最终金额、类别、账户和实际交易日期。OCR 结果可能有错，尤其是混合原价、折扣和多个商品时。即使只有一个候选也要核对。确认下单/支付已成功后才能入账，截图本身不是付款成功证明。

对同一文件内容使用哈希防重复导入，不同图片不会仅因同金额被阻止。重新压缩或裁剪后的图片内容不同，仍需人工避免重复。

## 自定义规则，无需每次重装

在工具页添加规则，选择手机里已安装应用或填写包名，设置平台/账户名称、触发文字，以及按优先顺序排列的金额标签。

- 可选择“实际点击指定按钮”触发，或“页面出现指定成功文案”触发。
- 金额标签是普通文字，不是可执行脚本。规则只创建待确认，不代替用户点击付款、不输入密码。
- 用本地诊断读到的文字测试；模拟测试不会付款或入账。
- 保存、启用、停用、删除规则会通知已运行的无障碍服务更新包名列表。服务须在系统中已开启。
- 页面不暴露文字、按钮事件拿不到、不同流程需复杂关联时，规则不能突破限制，使用截图补记或另行适配。

## 诊断与隐私

诊断默认关闭。用户主动开启后，只在内存暂存最近一次事件、页面文字、金额判断，最多 10 分钟，到期自动清空，也可手动停止并清空。不会把诊断原文存入数据库或保存到规则。

手机号和长号码做基础遮盖，但收货地址等无法保证完全脱敏；界面明确告知后才开启。分享诊断内容之前需要自行检查个人信息。规则编辑器中的测试文本也只在当前界面内存中保留。

## 升级与验证范围

直接覆盖 0.1.4 / 0.2.0-pdd 的本会话试用包，不要卸载、清除数据或换签名。数据迁移不等于已经备份手机账本。

验证包括：58 项测试、Android Lint 无错误、APK v2 签名验证、同签名核对、无网络权限、内置中文模型与 arm64 原生库、16 KB 对齐检查。数据库测试覆盖 v2→v4 和 v3→v4、金额误识别、忽略删除、还款排除与恢复、购物/付款关联和截图去重。

本云环境没有连接 OPPO PKB110：真实应用读屏、系统悬浮窗、图片解码与 ML Kit 原生识别链路仍需手机试用。五张截图用于设计文字规则与价格回归，没有将用户原图、地址、姓名或银行卡信息存入源码仓库。不能把文字样例测试描述为已经在真实支付页面或截图上完成端到端识别。

## 开发

JDK 17、Android SDK 36：

```sh
cd jianjizhang
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --no-daemon --max-workers=2
```

构建依赖需要网络，安装后的 App 不需要。Debug 签名文件不上传仓库；后续覆盖升级需沿用本会话已有签名。
