# 简记账 0.1.4：OPPO Find X8 试用说明

来源：https://github.com/jinyule/bookkeeping
源码提交：e09c8eae9be239d647c49c1d1b851ef24cd792ff
本包为原版源码编译的 Debug 试用版，不是开发者官方发行版。

## 安装

1. 在手机上下载 APK，使用系统文件管理器打开。
2. 如果系统要求，为打开 APK 的浏览器或文件管理器允许“安装未知应用”；装完可关闭此权限。
3. 应用名称为“简记账”，包名 com.github.bookkeeping。
4. 不需要 Root、Shizuku、账号或服务器。不要卸载已有同包名账本来解决签名冲突，以免丢失数据；如提示冲突请先停止并反馈。

## 权限与来源

进入简记账底部“自动”页面：

1. 保持“自动记账已开启”。
2. 点“通知识别”的“开启”，在系统里启用“简记账通知识别”的通知使用权。
3. 点“无障碍识别”的“开启”，在系统无障碍设置里开启“简记账无障碍识别”。
4. 首轮只保留“微信支付”和“支付宝”来源，其余来源关闭，以减少重复记录和误判。
5. 如提示请求发送通知，可以允许，用于应用的测试通知。发送通知权限与读取其他应用通知的“通知使用权”是两种权限。

OPPO 不同 ColorOS 版本菜单可能不同，可以在设置中搜索“通知使用权”“无障碍”“后台活动”“自启动”。若系统对侧载应用提示“受限设置”，先核对安装包来源，再查看应用信息页是否提供“允许受限设置”；没有该入口时不要尝试关闭系统安全防护，反馈提示原文即可。

如锁屏后漏记，在系统应用耗电管理中查看是否允许后台活动；有自启动选项时开启，并在最近任务中锁定应用。以上设置不能保证服务永不被系统停止。

## 验证顺序

1. 点“自动”页里的测试通知按钮；授权发送通知后如首次只完成授权，再点一次。检查是否生成“示例咖啡”36 元测试账单，完成后删除。
2. “无障碍识别测试”使用的是模拟文本，只验证解析功能，不证明微信真实页面可被读取。测试生成的账单应删除。
3. 下次真实小额消费时分别验证微信和支付宝。不要为测试专门向陌生人转账。
4. 验证金额、收支方向、商户、类别及有无重复；点账单查看详情并编辑保存。
5. 再测试出示付款码、锁屏一段时间后的支付，以及重启手机后服务是否仍开启。

## 当前能力边界

原版不是“每笔都弹出分类确认卡片”。较高置信度交易直接入账，较低置信度显示待确认；可在应用内编辑。主 Manifest 没有悬浮窗权限，也没有专门的每笔弹窗服务。若要逐笔确认，需要另行开发。

微信和支付宝的通知内容、页面可读性及 ColorOS 后台管理会影响识别率。无通知、不可读取或不显示结果页的交易可能漏记。当前包尚未在 OPPO PKB110 真机验证。

本机账单请勿随意卸载、清除应用数据。原版 manifest 关闭了系统备份；此试用包不能被当作唯一账本。
