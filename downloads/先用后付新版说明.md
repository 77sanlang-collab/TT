# 简记账 0.2.0-pdd 个人试用升级版

[电脑下载新版 APK](https://github.com/77sanlang-collab/TT/raw/refs/heads/main/downloads/jianjizhang-0.2.0-pdd-debug.apk)

## 安装与开启

1. 电脑下载 APK，通过微信文件传输助手传到手机。
2. 在手机文件管理器打开 APK，直接覆盖此前的 0.1.4 试用包；不要卸载旧版。新版包名和签名保持一致，数据库增加订单表，旧账单迁移保留。
3. 开启“自动”页的“拼多多下单 / 先用后付”来源，检查通知识别与无障碍识别仍已启用。更新后如服务没有生效，先在系统设置中关闭再开启“简记账无障碍识别”。
4. 首页进入“拼多多订单 / 先用后付”，开启订单待确认提醒；需要允许应用发送通知。

## 按本次截图增加的流程

- 只看商品或提交页，不记消费。
- 检测到多多支付的“提交订单”点击时，读取提交金额并生成待确认记录。
- 检测到先用后付的“0元下单，确认收货后付款”点击时，读取之后应付的金额。截图示例应取 3.99 元，不是 0 元，也不是划线价 9 元。
- 点击不等于下单成功。你确认下单确已成功后，核对实际金额（优惠后金额可能变化）、分类和下单日期，再点“确认入账”。先用后付同时显示待扣款余额，多多支付不计入该负债余额。
- 提醒使用系统通知，点开进入确认页，尚不是跨应用悬浮确认窗口。未允许提醒时仍可从首页查看待确认订单。
- 日后扣款，只有订单号、金额等证据明确匹配时自动结清。信息不足时手动关联原订单；关联后的扣款不再计第二笔消费。
- 不能读取页面按钮文字或点击事件时不会截图，可以在订单页补记；实际 OPPO 识别效果仍需真机验证。

## 已验证与边界

- 37 项测试通过，包含提交前不入账、两种支付方式金额提取、实际 Room 数据库确认/结清/撤销/取消流程、以及旧账单迁移。
- APK 无 INTERNET 权限，沿用原试用包签名。
- 不保存提交页整页原文、收货地址或截图。
- 普通微信扣款如未注明拼多多/先用后付，仍可能先成为普通支出，需要在订单里手动关联以消除重复。
- 部分退款、拆单和分次扣款暂不自动处理。不能用“取消整单”代替部分退款。
- 上游原版没有完整数据库导出功能；重要账单请另外留存，覆盖升级不代表已完成真机备份。
